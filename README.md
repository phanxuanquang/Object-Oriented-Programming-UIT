# Lập trình hướng đối tượng UIT

Lời giải C++ cho tất cả bài thực hành môn Lập trình hướng đối tượng, Trường Đại học Công nghệ Thông tin (UIT).

**Xem trên website:** https://phanxuanquang.github.io/Object-Oriented-Programming-UIT/

Bài làm chỉ mang tính chất tham khảo. Đây là môn học nền tảng cho sự nghiệp phát triển phần mềm, vì vậy hãy hiểu thật sâu các khái niệm thay vì sao chép lời giải.
